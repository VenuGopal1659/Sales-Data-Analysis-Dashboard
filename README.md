# Sales Data Analysis Dashboard

## 📊 Project Overview

This project focuses on analyzing sales data and creating an interactive dashboard using **Microsoft Power BI** and **Microsoft Excel**.

The dashboard provides a clear view of sales performance and helps identify important trends, product performance, and business insights.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* DAX
* Power Query
* Data Cleaning
* Data Visualization

## 📈 Dashboard Features

* Total Sales analysis
* Sales performance analysis
* Monthly sales trends
* Product/category performance
* Regional sales analysis
* KPI cards
* Interactive filters and slicers
* Data visualizations

## 🔍 Key Analysis

The dashboard helps analyze:

* Overall sales performance
* Sales trends over time
* Top-performing products
* Category-wise sales
* Region-wise performance
* Business performance using KPIs
